算法：IPPO (Independent Proximal Policy Optimization)

初始化：
    对于每个智能体 i ∈ {1,2,...,n}:
        初始化策略参数 θi
        初始化价值函数参数 φi
        创建经验回放缓冲区 Di

参数：
    小批量大小 minibatch_size
    折扣因子 γ
    GAE参数 λ
    裁剪参数 ε
    策略更新轮数 K
    熵系数 β

训练循环:
    for episode = 1, 2, ... do:
        重置环境，获取初始观察 o = {o¹, o², ..., oⁿ}
        
        for t = 1, 2, ... until 终止 do:
            对于每个智能体 i:
                基于策略πi(ai|oi;θi)选择动作ai
                记录动作概率 pi = πi(ai|oi;θi)
            
            将动作集合 a = {a¹, a², ..., aⁿ} 发送到环境
            获取奖励 r = {r¹, r², ..., rⁿ}, 新观察 o' = {o'¹, o'², ..., o'ⁿ} 和终止信号 done
            
            对于每个智能体 i:
                将 (oi, ai, ri, o'i, done, pi) 存储到Di中
                oi ← o'i

        如果满足更新条件:
            对于每个智能体 i:
                # 计算优势估计
                从Di中提取经验 {(oi_j, ai_j, ri_j, o'i_j, done_j, pi_j)}j=1^T
                使用GAE计算优势估计值 Âi_j
                归一化优势估计 Âi_j ← (Âi_j - mean(Âi_j)) / std(Âi_j)
                计算目标值函数 V̂target = Âi + V(oi)
                
                # 进行K轮策略优化
                for k = 1, 2, ..., K do:
                    随机打乱经验顺序并分成小批量
                    对于每个小批量:
                        # 策略网络更新
                        计算新策略概率 π'i(ai|oi;θi)
                        计算比率 ri(θi) = π'i(ai|oi;θi) / pi_j
                        计算裁剪目标 L^CLIP = min(ri(θi) * Âi_j, clip(ri(θi), 1-ε, 1+ε) * Âi_j)
                        计算熵奖励 S[πi](oi)
                        最大化目标： J(θi) = 𝔼[L^CLIP - β * S[πi](oi)]
                        更新策略参数 θi

                        # 价值网络更新
                        计算价值损失 L^VF = (V(oi;φi) - V̂target)²  或 Huber损失
                        如果使用ValueClip:
                            计算裁剪价值 V_clip = V_old + clip(V(oi;φi) - V_old, -ε, ε)
                            价值损失 L^VF = max(L^VF, (V_clip - V̂target)²) 
                        最小化L^VF更新价值参数 φi
                
                清空经验回放缓冲区 Di
