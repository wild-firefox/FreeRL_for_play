## 竞彩足球决策系统
这是一个基于强化学习的竞彩足球结果预测系统，使用MAPPO算法进行训练。  
这里的数据为2021年至2025年5月20日的竞彩足球数据，包含了胜平负、让球、大小等多种投注方式，为作者某宝上自费购得，这里开源给大家，但需遵守店铺中不得以商业形式使用的要求。    
如果这个库对你有帮助，欢迎star，因为这个环境构建花费了不少时间和金钱，感谢你的支持！

如果你有其他的对库改进的或者收集数据来重建环境的能力，欢迎与我联系，联系方式在github主页上。

## 环境简单介绍：
```
为简便环境，这里只进行单场投注和两场组合投注(即，可以设计成两智能体的环境)
动作：n x ([不可投注,胜, 平, 负, 胜平, 胜负, 平负, 胜平负, 不投注] 9个)
状态：n x ( 自身状态:[胜平负赔率(7*2*3),让球盘口赔率(4*2*3),大小盘口赔率(4*2*3)]  # 共90个信息 )
奖励：和现实足彩一致，投注成功则获得赔率乘以投注额的奖金，投注失败则损失投注额
```

## 一些思考：
这个库不能做到很好的创造收益大概是因为这个问题没能很好的建模成一个马尔可夫性质的问题，这里的当前状态和上一个状态无关。  

可以尝试将一个联赛中当前队的历史记录当作上一个状态，这样状态间就有关系了。可以参考b站视频：https://www.bilibili.com/video/BV1oc411R7PU/  。

这里的状态是当前比赛的赔率和盘口信息，可能还需要加入更多的上下文信息，比如球队的历史表现、球员状态等，但是数据收集上就比较耗费时间,精力或者财力了。
